# 出稿前チェックリスト

ページを書き終えたら、公開前に次を確認する。

## 実装との一致

- [ ] 書いた値（色、余白、角丸、時間、イージング）を `packages/tailwindcss/src` で確認した
- [ ] 確認していないことを、確認したかのように書いていない
- [ ] CSS 変数として配布しているものと、していないものを区別して書いた
- [ ] `:::raw` の描画と、直後のコードブロックのマークアップが一致している
- [ ] 例に使った属性（`aria-controls` の参照先、`id`）が実在する

## 分類

- [ ] 尺度は `tokens/`、使い方の指針はその対象のページ、場面は `recipes/`、価値観は `principles/` に置いた
- [ ] 指針のために独立したセクションを新設していない
- [ ] コンポーネントのページにバリアント名の見出し（`## Small` など）を作っていない

## 単一の情報源

- [ ] 同じ内容を `packages/tailwindcss/README.md` と docs の両方に書いていない
- [ ] 既存ページと重複する説明を新しく書いていない。重複するならリンクにした

## 導線

- [ ] `packages/docs/.vitepress/config.mts` の `sidebar` に追加した
- [ ] 本文中から内部リンクを張った（サイドバーからしか辿れないページを作らない）
- [ ] ページを移設した場合、旧パスへの参照が残っていない

## 文章

- [ ] [japanese-prose.md](japanese-prose.md) を読んで推敲した
- [ ] 一文一行になっている
- [ ] 「重要なのは〜である」「正面から扱う」「多角的」のような中身のない型を使っていない
- [ ] 同じ主張を言い換えて繰り返していない
- [ ] 見出しが節の結論の言い切りになっていない
- [ ] 未完了の TODO（「加筆が必要です」など）を公開文書に残していない。Issue に移した

## 検証

- [ ] `pnpm -F @jumpu-ui/docs build` が緑（リンク切れはここで落ちる）
- [ ] `pnpm format` を実行した
- [ ] `pnpm -F @jumpu-ui/docs dev` で描画とサイドバーを目視した

## 実装の不整合を見つけた場合

- [ ] 実装を直さず、現状を正確に書いた
- [ ] Issue に起票した
