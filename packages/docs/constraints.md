# 現状の制約

Jumpu UI がまだ対応していないこと、揃っていないことを記載します。
方針として対応しないと決めたものではありません。

## 未対応

**ダークモード**は未対応です。
配色は明るい背景を前提にしており、`prefers-color-scheme` を見る指定はありません。

**`prefers-reduced-motion`** は未対応です。
[遷移](/tokens/interaction)を無効にする指定がないため、動きを減らす設定にしている利用者にもアニメーションが再生されます。

**文言のガイドライン**は未整備です。
ボタンのラベル、エラーメッセージ、空の状態の表現について、指針を持っていません。

## 揃っていないこと

**ホバーとアクティブの表現**が 4 系統に分かれています。
明度を下げるものと背景色を変えるものが混在し、OutlinedButton のアクティブだけは明度を上げています。
詳細は [Interaction](/tokens/interaction) を参照してください。

**リンクとして使えるのにホバーの指定がない**コンポーネントがあります。
Avatar、Card、BoxedTabs の 3 つです。

**余白の系統**が 2 つ混在しています。
文字サイズに追従するコンポーネントと、しないコンポーネントがあります。
詳細は [Spacing](/tokens/spacing) を参照してください。

**行の高さの与え方**が揃っていません。
同じ `--text-xs` に対して、Tag と FilledTag は `--text-xs--line-height` を、IconButton は `--leading-tight` を使っています。

**役割を表す色の変数**がありません。
境界色は `gray-300` を各コンポーネントに直接書いているため、まとめて変更することができません。

## 変数として配布していない値

[遷移時間とイージング](/tokens/interaction)、[ホバーとアクティブの明度差](/tokens/interaction)は、コンポーネントの CSS に直接書かれています。
尺度としては決まっていますが、`@theme` で上書きすることはできません。

**Accordion が APG の構造を取れません。**
開閉ボタンを見出し要素で包むと、CSS が直下の子だけを対象にしているためスタイルが当たらなくなります。
詳細は[アクセシビリティ方針](/principles/accessibility)を参照してください。

## アイコンセットへの依存

一部のコンポーネントが Font Awesome Free の SVG を埋め込んでいます。
詳細は [アイコン](/content/icons) を参照してください。
